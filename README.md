# AlmacenesDatosEDA
Este proyecto gestiona el ciclo inicial de gobernanza de datos: desde recibir ficheros heterogéneos hasta dejarlos listos para analizar en una plataforma corporativa. Tras realizar el EDA y corregir errores, los datos se integran, documentan y transforman en Dremio, logrando información fiable y trazable para tomar decisiones.
